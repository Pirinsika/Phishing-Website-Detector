# Phishing Website Detector
## Project Overview
A Python-based phishing website detection project that analyses website-related data and identifies potentially suspicious websites.
## Objectives
- Understand phishing website detection.
- Classify websites as phishing or legitimate.
- Calculate phishing risk scores.
- Visualize detection results.
## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn
## Project Implementation
The project uses sample test cases to demonstrate phishing detection and classification. It displays classification results, confidence scores, and phishing risk percentages.
## Current Limitations
The current version uses predefined test cases and does not yet provide a live URL input interface.
## Future Improvements
- Implement user-provided URL detection.
- Extract URL-based features.
- Build an interactive web interface.
- Improve detection accuracy using machine learning.
## Project Status
Basic prototype completed. Further development planned.
